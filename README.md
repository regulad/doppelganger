## Building requirements

Mac build dependencies (from `brew`):

- `flock`

There are some files in this repository (mainly patches into legacy code) that are generated yet still need to be committed into the tree.

## Building notes

These files are generated by the turborepo task `precommit`. Run `turbo precommit` before finalizing any commits if you have altered code that generated files are dependent on. The git hook should prevent any pushes that have out-of-date generated files, and the CI will reject any commits that update the files that are generated without a proper regeneration.

The code used to evaluate the "recency" of generated files depends on some possibly unintended behavior of turborepo. Ensure that the turbo on your path matches what is specified in the lockfile (if you correctly installed the package, this shouldn't be a problem). Ensure that you are logged into the `nefum` Vercel organization so the cache correctly gets updated with new generated data.

The `Dockerfile` for `apps/web` is not linted and not verified. Please edit it with caution and test offline before pushing.
